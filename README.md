# What this project is
A public repository of my tool made in C++. A "Course Record, Grade Estimate & Study Plan by extension" tool. I guess.

# How to run it (tentative)
Inside the release tab there is two releases, if a version is tagged with a version tag, a versioned release will be created on successful build; else every successful build triggers the "latest" release, download the .zip according to your platform and unzip it for the .exe. program.
